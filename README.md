# C# Veri Filtreleme ve Raporlama Sistemi

## Proje Açıklaması
Bu projede kullanıcıdan alınan ad ve soyad bilgisine göre veritabanında arama yapılır.
Bulunan kayıtlar Crystal Report ile raporlanır.

## Kullanılan Teknolojiler
- C#
- Windows Forms
- Access Database
- Crystal Report

## Özellikler
- Veri filtreleme
- Kullanıcı etkileşimi (MessageBox)
- Dinamik raporlama
